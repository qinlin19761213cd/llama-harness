# 审计维度与严重度判定

## 严重度定义
- **高 (High)**：崩溃、数据损坏、安全漏洞、明确的功能错误、不可恢复的故障
- **中 (Medium)**：边界/异常路径错误、性能退化、资源泄漏、可维护性硬伤
- **低 (Low)**：代码风格、冗余、注释缺失、命名、轻微可维护性

## 检查维度（默认全量，用户可收窄）

### 1. 正确性
- 空值 / 越界 / 除零 / 类型转换错误
- 边界条件（0、1、max、空集合、Unicode、超大输入）
- 状态机遗漏分支、错误路径未处理
- 数据竞态（共享可变状态、非原子读改写）
- 浮点/精度问题、时区问题

### 2. 安全
- 注入：SQL / 命令 / 路径穿越 / XSS / SSTI
- 认证授权：硬编码凭据、缺失鉴权、越权访问
- 敏感数据：日志泄露密钥/token/PII、明文存储密码
- 不安全的反序列化、SSRF、开放重定向
- 依赖：已知漏洞版本（CVE）、过期依赖

### 3. 性能
- N+1 查询、循环内 IO/网络、无索引查询
- 大对象无界增长、内存泄漏、缓存失效风暴
- 阻塞调用阻塞异步路径、锁竞争
- 热点路径重复计算、未复用中间结果

### 4. 并发
- 共享可变状态无同步、死锁、活锁、饥饿
- 原子性缺失（check-then-act）、可见性缺失
- 任务/线程泄漏、未取消的 CancellationToken
- 幂等性：重试导致副作用重复

### 5. 可维护性
- 巨型函数/类、深层嵌套、魔法数字
- 复制粘贴代码、职责混杂、隐式耦合
- 错误处理吞异常、无日志、无观测埋点
- 命名/注释与实现不符

### 6. 依赖与构建
- 死代码/未使用依赖、循环依赖
- 构建可复现性、硬编码路径、环境假设
- 版本锁定缺失、传递依赖风险

### 7. 测试
- 关键路径缺测试、断言弱（只跑不验）
- 测试依赖时序/外部状态、偶发失败
- 覆盖率与风险不匹配（高风险代码低覆盖）

### 8. 配置与环境
- 配置魔法值硬编码、环境差异未抽象
- 敏感配置进版本库、默认配置不安全

## 语言特定检查（按项目语言加载对应节）

### Python
- 可变默认参数、异常被吞、`with` 资源未关
- f-string/路径拼接注入、`eval`/`exec`、反序列化（pickle/yaml.load）
- GIL 误区、大循环内调用、无缓存的热点

### C# / .NET
- `async void`、缺 `ConfigureAwait`、`IDisposable` 泄漏
- LINQ 多次枚举、字符串拼接热路径、阻塞 `.Result`/`.Wait()`
- `CancellationToken` 未传递、异常被吞、`catch (Exception)` 空块

### JavaScript / TypeScript
- 未 `await` 的 Promise、回调地狱、隐式 `any`
- 原型污染、XSS 渲染（`innerHTML`）、依赖注入路径穿越
- 内存泄漏（事件监听器、定时器未清理）

### Go
- goroutine 泄漏、错误被吞、`defer` 循环、并发 map 写入
- slice 别名陷阱、`interface{}` 滥用、未用 `context` 取消

### Rust
- `unsafe` 块、`unwrap` 恐慌、生命周期泄漏、`Arc` 循环引用
- 无界 `Vec`/缓存、`Mutex` 误用、错误传播缺失

### Java
- 空指针、受检异常被吞、线程安全集合误用
- 资源未关（Stream/Connection）、字符串 `+` 热路径、缓存无界
